# Portfolio Operations Dashboard (Demo)

**Live demo:** https://nathansabony.github.io/ops-dashboard-demo/

A public, simplified version of an internal operations dashboard I built for a real estate company. The real tool pulls portfolio financials together through live API connections. This demo recreates the same ideas with **made-up sample data** (`data.js`):

- KPI tiles: property count, average occupancy, monthly revenue, NOI
- 12-month NOI trend chart
- Occupancy by property
- Expense variance tracker (actual vs. budget) that flags properties to watch or review
- Filters by region and month

No real company data or code is included.

Built with plain HTML, CSS, and JavaScript. Part of my portfolio: https://nathansabony.github.io/
